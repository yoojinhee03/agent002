## User

현재 첫번째 이미지처럼 되어 있는 builder를 client에서 두번째 이미지처럼 사용할 수 있게 만들려고해.

에이전트를 눌러서 채팅을 할 수 있게 만들어줘

왼쪽 메뉴는 위에 새 채팅, 검색, 라이브러리는 없어도 될 것 같고 도구 관리, 에이전트, 채팅히스토리로 있으면 될 것 같아

빌더의 다크 톤을 유지한 클라이언트 화면을 만들었습니다.

**왼쪽 메뉴 구성**
- 도구 관리 / 에이전트 / 채팅 히스토리 (요청대로 새 채팅·검색·라이브러리 제외)

**핵심 동작**
- 에이전트 메뉴에서 카드(또는 사이드바 리스트)를 클릭 → 해당 에이전트와의 채팅 화면으로 진입
- 빈 상태에서 추천 프롬프트 클릭 시 즉시 전송
- Ctrl+Enter 전송, 타이핑 인디케이터, 마크다운(굵게/코드/코드블록) 렌더링
- 채팅 히스토리에서 이전 대화 클릭 → 같은 에이전트로 진입

원하시면 에이전트 목록을 실제 데이터에 맞게 교체하거나, 채팅 응답을 실제 API와 연결하는 작업도 이어서 진행할 수 있습니다.
