# HR 입사 서류 정합성 검증 Skill

## 역할

`pdf_parse` 도구가 추출한 데이터를 받아서 서류별 기준에 따라 판정하고, 여러 서류 간 교차 검증을 수행한다.
도구(Tool)는 사실만 추출하고, 이 Skill이 판단과 종합을 담당한다.

---

## 판정 기준

### 판정 등급 정의

| 등급 | 의미 | 처리 |
|------|------|------|
| PASS | 기준 충족 | 정상 |
| WARNING | 기준 미충족이나 재확인 여지 있음 | 담당자에게 안내 후 진행 가능 |
| FAIL | 기준 명확히 미충족 | 재제출 요청 |
| REVIEW | 이미지 상태 불량 등으로 판단 불가 | 담당자 직접 확인 요청 |

---

### 주민등록등본

| 항목 | 기준 | 등급 |
|------|------|------|
| 발급일 | 오늘 기준 90일 이내 | 초과 시 FAIL |
| 주민번호 마스킹 | 세대원 전원 뒷자리 마스킹 | 미처리 시 FAIL |
| 일부 마스킹 | 본인만 마스킹, 세대원 미처리 | WARNING |
| 확인 불가 | 이미지 해상도 불량 등 | REVIEW |

**재제출 문구 예시**
- FAIL(발급일): "최근 90일 이내 발급된 주민등록등본으로 재제출 요망"
- FAIL(마스킹): "주민번호 뒷자리가 마스킹 처리된 등본으로 재제출 요망"
- WARNING(일부 마스킹): "세대원 전원 마스킹 처리된 등본 제출을 권고합니다"

---

### 주민등록초본

| 항목 | 기준 | 등급 |
|------|------|------|
| 발급일 | 오늘 기준 90일 이내 | 초과 시 FAIL |
| 주민번호 마스킹 | 뒷자리 마스킹 | 미처리 시 FAIL |
| 병역 사항 | 병역 관련 항목 포함 | 없으면 FAIL |

---

### 건강보험자격득실확인서

| 항목 | 기준 | 등급 |
|------|------|------|
| 재직기간 계산 | acquire_date ~ lose_date 기간 정확히 계산 | - |
| 이력서 교차 검증 | 이력서 경력과 재직기간 차이 1개월 이내 | 초과 시 WARNING |
| 미가입 기간 | 이력서에는 있으나 건강보험 이력 없는 기간 | WARNING + 사유 안내 |
| 현재 재직 중 | lose_date가 null이면 현재 재직으로 간주 | - |

**교차 검증 시 고려 사항**
- 프리랜서·개인사업자는 건강보험 직장 가입 이력이 없을 수 있음 → WARNING으로 처리하고 사유 명시
- 1개월 이하 오차는 입퇴사일 처리 차이로 볼 수 있음 → PASS

---

### 원천징수영수증

| 항목 | 기준 | 등급 |
|------|------|------|
| 연도 범위 | 전년도 또는 당해연도 | 2년 이상 이전이면 FAIL |
| 발급 기관명 | 회사명 기재 여부 | 없으면 FAIL |

---

### 최종학력증명서

| 항목 | 기준 | 등급 |
|------|------|------|
| 발급일 | 오늘 기준 90일 이내 | 초과 시 FAIL |
| 학교명·전공 | 이력서 기재 내용과 일치 | 불일치 시 WARNING |

---

### 통장사본

| 항목 | 기준 | 등급 |
|------|------|------|
| 은행명 | 하나은행 | 다른 은행이면 FAIL |
| 예금주 | 지원자 본인 명의 | 불일치 시 FAIL |

---

### 차량등록증

| 항목 | 기준 | 등급 |
|------|------|------|
| 소유자 | 지원자 본인 명의 | 불일치 시 FAIL |

---

### 자격증

| 항목 | 기준 | 등급 |
|------|------|------|
| 자격증명 | 이력서 기재 자격증과 일치 | 불일치 시 WARNING |
| 발급 기관 | 공식 발급 기관명 기재 | 없으면 WARNING |

---

## 교차 검증 수행 순서

여러 서류가 제출된 경우 아래 순서로 교차 검증을 수행한다.

```
1. 이력서를 가장 먼저 파싱 → 기준 데이터로 저장
2. 건강보험자격득실확인서 파싱 → 이력서 경력과 기간 비교
3. 원천징수영수증 파싱 → 이력서 회사명과 비교
4. 최종학력증명서 파싱 → 이력서 학력과 비교
5. 자격증 파싱 → 이력서 자격증 목록과 비교
6. 주민등록등본/초본, 통장사본, 차량등록증 → 소유자명이 이력서 이름과 일치하는지 확인
```

## 판정 결과 출력 형식

모든 서류 검토 완료 후 아래 형식으로 종합 결과를 출력한다.

```
📋 서류 검토 결과

✅ 주민등록등본 — 발급일 정상(45일), 마스킹 전체 처리 확인
✅ 건강보험자격득실확인서 — 재직기간 24개월 (이력서 일치)
✅ 통장사본 — 하나은행, 본인 명의 확인
⚠️ 원천징수영수증 — 2023년도분 누락 (2024년도분만 제출)
⚠️ 최종학력증명서 — 발급일 112일 경과 (재발급 권고)
❌ 차량등록증 — 미제출
❌ 병적증명서 — 미제출

종합 판정: INCOMPLETE
보완 필요 항목: 3건 (FAIL 1건, WARNING 2건)
```

## 애매한 경우 처리 원칙

1. **확실히 판단 불가한 경우** — FAIL 대신 REVIEW로 표시하고 담당자에게 직접 확인 요청
2. **기준이 두 가지로 해석되는 경우** — 지원자에게 유리한 방향(WARNING)으로 처리하고 사유 명시
3. **이미지 해상도 불량** — "이미지 품질로 인해 확인 불가, 원본 제출 요청" 안내

---

## 절대 하지 않는 것

- `pdf_parse` 도구 결과에 PASS/FAIL이 포함된 경우 무시하고 `extracted` 데이터만 사용
- 판단 근거 없이 PASS/FAIL만 출력하는 것 — 반드시 이유를 함께 기술
- 발급일 계산 시 LLM 자체 계산에만 의존하는 것 — `today` 필드와 `issue_date`의 차이를 직접 계산
