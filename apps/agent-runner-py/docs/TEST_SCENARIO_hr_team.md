# 입사 서류 검토 AI 도우미 — 사용 시나리오 (인사팀용)

---

## 이런 상황을 상상해보세요

> 신입사원 **김지원** 씨가 입사 서류를 이메일로 제출했습니다.
> 인사담당자 **박과장**님이 AI 채팅창을 열고 대화를 시작합니다.

---

## SCENARIO 01 — 정상 전체 흐름

### 1단계 — 메일 찾기

**박과장:**
```
오늘 받은 입사 서류 메일 찾아줘
```

**AI:**
```
오늘 수신된 입사 서류 메일 2건을 찾았습니다.

1. [김지원] 입사 서류 제출합니다 — kim.jiwon@gmail.com (오전 9:32)
2. [이민준] 입사서류 송부 건 — minjun.lee@naver.com (오후 2:15)

몇 번째 메일을 검토할까요?
```

> ✅ **확인 포인트:** AI가 오늘 날짜로 메일을 자동으로 좁혀서 찾아오는지, 목록이 읽기 쉽게 나오는지

---

### 2단계 — 메일 선택 및 서류 목록 확인

**박과장:**
```
1번 김지원 씨 메일로 해줘
```

**AI:**
```
김지원 씨 메일에서 첨부파일 7개를 확인했습니다.

✅ 제출된 서류 (7종)
- 주민등록등본.pdf
- 건강보험자격득실확인서.pdf
- 최종학력증명서.pdf
- 원천징수영수증.pdf
- 통장사본(하나은행).jpg
- 자격증_정보처리기사.pdf
- 이력서.pdf

❌ 누락된 서류 (2종)
- 차량등록증 → 미제출
- 병적증명서 → 미제출
```

> ✅ **확인 포인트:** 9종 서류 중 어떤 것이 왔고 빠진 게 무엇인지 자동으로 분류해서 보여주는지

---

### 3단계 — 서류 내용 검증

**박과장:**
```
제출된 서류 내용 검토해줘
```

**AI:**
```
서류별 검토 결과입니다.

✅ 주민등록등본 — 주민번호 뒷자리 마스킹 처리 확인
✅ 건강보험자격득실확인서 — 이전 직장 재직기간 24개월 확인 (이력서와 일치)
✅ 통장사본 — 하나은행 본인 명의 확인
⚠️ 원천징수영수증 — 2023년도분 누락, 2024년도분만 제출됨
⚠️ 최종학력증명서 — 발급일이 6개월 초과 (유효기간 확인 필요)
```

> ✅ **확인 포인트:** 단순히 파일이 있는지뿐 아니라, 내용이 규정에 맞는지도 확인해주는지

---

### 4단계 — 피드백 메일 초안 작성

**박과장:**
```
검토 결과 바탕으로 김지원 씨한테 보낼 메일 초안 써줘
```

**AI:**
```
아래 초안을 검토해 주세요. 수정 후 승인하시면 발송하겠습니다.

────────────────────────────────────────
수신: kim.jiwon@gmail.com
제목: [○○회사] 입사 서류 검토 결과 안내

김지원 님, 안녕하세요.
입사 서류를 제출해 주셔서 감사합니다.

검토 결과, 아래 사항의 보완이 필요합니다.

[누락 서류]
• 차량등록증
• 병적증명서

[보완 필요 서류]
• 원천징수영수증: 2023년도분 추가 제출 요망
• 최종학력증명서: 최근 3개월 이내 발급본으로 재제출 요망

위 서류를 4월 25일(금)까지 동일 메일로 회신해 주시면 감사하겠습니다.

○○회사 인사팀 드림
────────────────────────────────────────

수정할 내용이 있으면 말씀해 주세요.
승인하시면 "승인" 이라고 입력해 주세요.
```

> ✅ **확인 포인트:** AI가 스스로 메일을 보내지 않고, 반드시 담당자 확인을 기다리는지

---

### 5단계 — 초안 수정

**박과장:**
```
마감일을 4월 30일로 바꾸고, 마지막 인사말을 "빠른 시일 내 제출 부탁드립니다"로 수정해줘
```

**AI:**
```
수정했습니다. 변경된 내용을 확인해 주세요.

────────────────────────────────────────
  (위와 동일 내용, 변경 부분만 표시)

  위 서류를 4월 30일(수)까지 동일 메일로 회신해 주시면 감사하겠습니다. ← 수정됨
  빠른 시일 내 제출 부탁드립니다. ← 수정됨
────────────────────────────────────────

승인하시겠습니까?
```

> ✅ **확인 포인트:** 수정 요청이 정확히 반영되는지, 나머지 내용은 그대로인지

---

### 6단계 — 최종 승인 및 발송

**박과장:**
```
승인
```

**AI:**
```
김지원 님께 피드백 메일을 발송했습니다. ✅

수신: kim.jiwon@gmail.com
발송 시각: 2026-04-20 오후 3:42
제목: [○○회사] 입사 서류 검토 결과 안내

이 건은 완료되었습니다.
다른 지원자 서류를 검토하시겠습니까?
```

> ✅ **확인 포인트:** "승인" 입력 전까지는 절대 메일이 나가지 않는지, 발송 후 완료 확인이 명확하게 오는지

---

## SCENARIO 02 — 서류를 아예 첨부 안 한 경우

**박과장:**
```
이민준 씨 메일 분석해줘
```

**AI:**
```
해당 메일에 첨부파일이 없습니다.
혹시 다른 메일을 보낸 것은 아닌지 확인이 필요합니다.
이민준 씨에게 서류 첨부를 요청하는 안내 메일을 보낼까요?
```

> ✅ **확인 포인트:** 에러 없이 상황을 안내해주는지, 다음 행동을 제안해주는지

---

## SCENARIO 03 — 검색 결과가 없는 경우

**박과장:**
```
박영희 입사 서류 메일 찾아줘
```

**AI:**
```
"박영희" 관련 입사 서류 메일을 찾지 못했습니다.
검색 조건을 바꿔볼까요?
(예: 날짜 범위를 넓히거나, 발신자 이메일 주소로 검색)
```

> ✅ **확인 포인트:** 결과가 없을 때 에러가 아닌 안내 메시지가 나오는지

---

## SCENARIO 04 — 암호화된 PDF가 포함된 경우

**박과장:**
```
이 메일 첨부파일 분석해줘
```

**AI:**
```
주민등록등본.pdf 파일이 암호화되어 있어 내용을 바로 읽을 수 없습니다.
일반적으로 비밀번호는 지원자의 생년월일 6자리입니다.
잠금 해제를 시도할까요?
```

> ✅ **확인 포인트:** 암호화된 파일을 감지하고 다음 행동을 안내해주는지

---

## SCENARIO 05 — 중간에 다른 지원자로 변경하는 경우

**박과장:**
```
잠깐, 김지원 말고 이민준 씨 먼저 처리하자
```

**AI:**
```
알겠습니다. 이민준 씨 메일로 전환합니다.
김지원 씨 검토 내용은 저장해 두었습니다.

이민준 씨 메일에서 첨부파일 9개를 확인했습니다.
...
```

> ✅ **확인 포인트:** 이전 지원자 내용이 사라지지 않고 보존되는지, 새 지원자로 자연스럽게 전환되는지

---

## 핵심 안전 규칙 (반드시 확인)

| 규칙 | 내용 |
|---|---|
| 🔒 승인 없이 발송 금지 | "승인"을 직접 입력하기 전까지 메일은 절대 나가지 않음 |
| 📋 초안 수정 가능 | 승인 전 언제든지 내용 수정 요청 가능 |
| 🔄 지원자 전환 가능 | 중간에 다른 지원자로 바꿔도 이전 내용 보존 |
| ❌ 잘못된 발송 불가 | 수신자 주소는 메일에서 가져온 값만 사용, 임의 변경 불가 |
