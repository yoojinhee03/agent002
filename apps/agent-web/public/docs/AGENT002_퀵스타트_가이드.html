1. AGENT002란?

AGENT002는 LangGraph 기반의 에이전트 하네스를 시각적으로 구성하고, 빌더 내부에서 바로 실행·디버깅한 뒤, 환경(Environment)별로 배포해 챗 클라이언트에서 사용할 수 있는 엔터프라이즈 AI Agent Management Platform입니다. 좌측 사이드바의 로고에는 "AGENT002"로 표기됩니다.

이 가이드는 두 종류의 독자를 모두 다룹니다.

  • 빌더 에이전트를 직접 만드는 사용자 (대시보드 영역)
  • 사용자 배포된 에이전트를 사용하는 일반 사용자 (/client 영역)

2. 로그인하기

웹 브라우저에서 서비스 주소(예: http://dweax.iptime.org:28002/)에 접속하면 자동으로 /login으로 이동합니다.

1 이메일 필드에 계정 이메일을 입력합니다. (예: user@example.com)
2 비밀번호 필드에 비밀번호를 입력합니다. 우측 눈 아이콘으로 비밀번호 표시/숨김 전환이 가능합니다.
3 파란색 [로그인] 버튼을 누르거나 Enter를 누릅니다. 인증 성공 시 자동으로 /dashboard로 이동합니다.
비밀번호를 잊으셨나요? 로그인 카드 하단의 [비밀번호를 잊으셨나요?] 링크를 누르면 [비밀번호 찾기 → 메일 전송 → 비밀번호 재설정] 3단계 흐름이 제공됩니다. 새 비밀번호는 6자 이상이어야 합니다.

5. 5분 만에 첫 에이전트 만들기 빌더

1 좌측 메뉴 [Agents]를 클릭합니다. 우측 상단에 [템플릿으로 시작 (준비 중)], [Import], [+ New Agent] 버튼이 표시됩니다.
2 파란색 [+ New Agent] 버튼을 누르면 "New Agent" 모달이 열립니다.
  • 에이전트 이름: 예) "마케팅 비서"
  • 설명: 에이전트의 역할이나 목적
[에이전트 생성] 버튼을 누르면 자동으로 빌더 캔버스(/agents/[agentId])로 이동합니다. 이때 systemPrompt 기본값은 "You are a helpful assistant.", 모델 기본값은 gpt-4o-mini입니다.
3 캔버스 좌상단에 "Main Agent" 노드가 표시됩니다. 우측 패널은 기본적으로 [Settings] 모드입니다.
4 우측 패널 → [프롬프트] 탭으로 이동해 system prompt를 작성합니다. Monaco 에디터에서 자유롭게 입력하고, 필요하면 Few-shot 메시지도 추가할 수 있습니다. 저장 후 자동으로 버전이 기록되어 [Versions]에서 되돌릴 수 있습니다.
5 우측 패널 → [모델] 탭에서 Brain Model · Temperature(0~2) · Max Tokens(256~32768)을 설정합니다.
6 [도구] 탭과 [Skills] 탭에서 필요한 항목을 체크해 활성화합니다. 도구는 Custom · MCP · Builtin 그룹으로 묶여 있고, 도구별 권한(allow/ask/deny)을 별도 설정할 수 있습니다.
7 멀티에이전트로 만들고 싶다면 캔버스 빈 곳을 우클릭(또는 캔버스의 + 아이콘)으로 Sub Agent 노드를 추가하고, Main Agent와 엣지로 연결합니다. 추가된 Sub Agent도 동일하게 우측 패널에서 프롬프트·모델·도구·Skills를 설정합니다.
8 상단 우측의 [💾 저장] 버튼을 누르면 변경 사항이 저장됩니다. "미저장" 배지가 사라지면 완료입니다.
Tip — Agent Assistant 패널 캔버스 하단에는 Agent Assistant 패널이 있어, 자연어로 "프롬프트를 정중한 어투로 다듬어줘"처럼 요청하면 변경 제안(diff)이 카드로 떠 클릭 한 번으로 적용할 수 있습니다.

6. 캔버스에서 테스트하기

1 캔버스 상단의 파란색 [▶ 실행] 버튼을 누릅니다.
2 우측 패널이 [Debug] 모드로 전환되며 입력창이 표시됩니다. 사용자가 보낼 법한 질문을 입력하고 전송합니다.
3 실행되면 캔버스의 노드와 엣지가 파란색으로 활성화되며 현재 어디까지 진행됐는지 시각적으로 표시됩니다. 오류가 나면 빨간색으로 표시됩니다.
4 [Debug] 패널에서 단계별 이벤트(StepFlowEvent)·도구 호출·토큰 사용량을 확인할 수 있습니다.
에이전트 목록에서 빠른 채팅 /agents 목록의 각 카드 우하단 [Chat] 버튼을 누르면 별도의 채팅 화면(/agents/[agentId]/chat)에서 빠르게 대화 테스트가 가능합니다.

7. 배포 및 API 키 발급

테스트 결과가 만족스러우면 배포를 진행합니다.

1 캔버스 상단 우측의 [🚀 배포] 버튼을 누르면 배포 관리 페이지(/agents/[agentId]/deployments)로 이동합니다.
2 "새 배포" 카드에서 환경(Environment)을 선택합니다. (예: dev / staging / prod)
3 "설명(릴리스 노트)"에 변경 내용을 적고 [배포 실행]을 누르면 "v{version} 배포 완료" 토스트가 뜨고 "배포 이력" 테이블에 새 행이 추가됩니다.
4 배포 이력에서 해당 행의 publicPath를 확인합니다. 옆의 복사 아이콘으로 한 번에 복사 가능합니다.
5 REST API로 호출하려면 [+ API 키 발급]으로 키를 발급합니다. 발급된 키는 노란색 카드로 한 번만 표시되며 이후에는 다시 볼 수 없으니 즉시 안전한 곳에 저장하세요. 함께 표시되는 curl 예시(thread 생성 → 메시지 전송)도 그대로 사용할 수 있습니다.
API 키 보안 한 번 표시된 키는 다시 조회 불가합니다. 의심이 들면 즉시 [폐기]하고 새로 발급하세요.

8. 챗 클라이언트(/client)에서 사용하기 사용자

배포된 에이전트는 같은 도메인의 /client 경로에서 일반 사용자가 사용할 수 있습니다.

1 /client 또는 /client/login에 접속해 로그인합니다.
2 좌측 사이드바 [에이전트] 메뉴에 "배포된 활성 에이전트"가 카드로 표시됩니다. 각 카드에는 환경 색상의 봇 아이콘, 이름, v{version} · {환경명}, 설명, 대화 시작 예시(starters)와 구성 칩(sub / skill / tool 개수)이 보입니다.
3 카드를 클릭하면 상세 페이지(/client/agents/[slug])가 열립니다.
  • 자격 증명이 모두 준비됐으면 녹색 "준비 완료" 카드가 뜹니다.
  • 누락된 자격 증명이 있으면 [도구 관리]로 이동하라는 안내가 표시됩니다.
4 상세 페이지에서 [채팅 시작]을 누르면 채팅 화면이 열리고 자연어로 대화하면 됩니다.
이력 이어가기 좌측 사이드바 [채팅 히스토리]에서 이전 대화를 클릭하면 같은 thread로 이어집니다. 상단의 검색창으로 제목/에이전트명 검색이 가능하고, 항목을 우클릭하면 [삭제]가 나옵니다.

9. 다음 단계

핵심 흐름을 익히셨다면 "AGENT002 사용자 메뉴얼"(표준 버전)에서 다음 내용을 더 자세히 확인할 수 있습니다.

  • Settings 패널의 8개 탭(기본/프롬프트/도구/Skills/모델/I/O/가드레일/Handoff) 사용법
  • Skills 페이지의 instructions 작성·파일 첨부·내보내기 / 가져오기

  • 배포 환경(Environment) 관리, 다중 배포 운영
  • Monitoring · Usage 대시보드 활용
  • 관리자 전용 Users / Slack 연동
